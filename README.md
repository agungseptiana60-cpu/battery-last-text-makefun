The phone battery's last text to the charger it waited for all day, in one line: "hey charger, I waited all day and you only showed up at 1% like a hero, so my last text is this: I'm dying, and I'm taking the Wi-Fi password with me." The program in `main.ts` writes that single line (150 characters) to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
